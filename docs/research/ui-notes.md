# FolderMarker 4.0 — UI analysis from App Store screenshots

Source: App Store listing id1012940117 (screenshots fm1.jpg–fm5.jpg in this folder).
FolderMarker by ImageStudio Pro (seller: Elena Drozhzhina), v4.0, $7.99 one-time, macOS 10.11+, ~9 MB.

## Main window (fm1, fm2, fm4)

- Dark, compact utility window. The content is a **grid of style tiles** (the "Styles"), each tile a large folder preview rendered with its style (color + overlay). Up to 40 editable styles per Asset, in a 4-wide grid.
- One special tile is **Restore** (blue folder labeled "Restore") which restores a folder's default/original icon when folders are dropped on it.
- Selected tile shows a name caption below ("Folder 7", "Ideas") and small action buttons above the tile (apply/play, edit, etc.).
- **Workflow: drag folders from Finder and drop them onto a style tile** to apply that style. Also supports selecting folders/tiles and pressing an apply (▶) button.
- **Toolbar** (left → right): new/export doc icon, share, iCloud, tag/label icon, then a full-width **rainbow hue slider** (drag to shift hue of the selected style live), then: apply (▶), emoji picker, symbols picker, **T** (text), image picker, and +/− (add/remove style).
- Menu bar menus: FolderMarker, File, Bar, Edit, Format, Settings, Tags, Labels, Window, Help.

## Floating panels (fm1, fm2)

- **Color panel**: color wheel + inner triangle (hue/sat/brightness), eyedropper button, Hex field + R/G/B numeric fields.
- **Symbols panel**: scrollable grid of monochrome "generic symbols" glyphs (money, mic, heart, mail, bell, house, boat, people, chef hat, etc.).
- **Assets panel**: list of Assets (style collections): "Main Asset" (locked), Images, Alphabet, Symbols, Emoji, Misc, Basic Colors, Numbers, Work, Text — with search field, add/remove buttons. Each asset holds its own set of up to 40 styles. Assets import/export by drag & drop, sync via iCloud Drive.

## Style editor (fm3, fm5)

Opens as a large popover/sheet over the grid with a big live folder preview. Tabs across the top: **Icons | Effects | Generic | Text** (plus image controls when an image is used).

- **Text tab**: font family + face selectors, text field, Apply; text is rendered embossed onto the folder; separate text color control; rotation handle (circular arrow at preview left edge); color shuffle button (rainbow circle at right of preview).
- **Bottom bar of editor**: mode toggle, scale slider, effect toggle buttons (shadow, fill, opacity, inner stroke, outer stroke), Cancel, Ok.
- **Image modes** (fm5): four compositing modes for user images:
  - **Image Fill** — image fills/covers the folder silhouette
  - **Image Stamp** — B/W image stamped/engraved into the folder color
  - **Image Over** — image composited on top of the folder icon
  - **Image Only** — image replaces the folder icon entirely
  - Image thumbnail well at bottom-right of preview with filename caption; drag your own images in.
- Effects: shadow, fill, opacity, inner stroke, outer stroke. Position, rotation and scale adjustable for images/overlays.

## FolderMarker Bar (fm4)

- A **status-bar companion**: menu bar icon plus a small floating "FolderMarker Bar" palette window showing the current asset's styles as a compact grid; drag folders onto its tiles (or the status bar icon) for fast colorizing without the main window.

## Other features (from App Store description)

- Drag & drop UI; marks multiple folders at once; works on folder aliases.
- Color via color wheel, hue slider, and Color Shuffle (random).
- Applies Finder color tags matching preset colors; folder labels as additional tags (Tags & Labels menus).
- Replacing and copying presets between slots.
- Restore default folder icon; **Smart Restore** keeps a saved copy of the folder's pre-existing icon so it can be restored later.
- Export styles as **ICNS** and as **iconset**; export/import styles and whole assets (drag & drop); iCloud sync of settings/assets.
- Touch Bar support, Apple silicon native.
